# РаботаРФ Render Ready

## Как залить
1. Создай GitHub репозиторий.
2. Загрузи все файлы из этой папки.
3. На Render нажми New -> Blueprint.
4. Выбери репозиторий.
5. Нажми Apply.
6. После деплоя открой Static Site.

## Важно
Backend URL для сайта меняется в `frontend/index.html` в строке `BEKEND_URL`.
Если Render дал backend не `https://rabota-rf.onrender.com`, замени на свою ссылку.
